Privacy Policy

Last updated: June 2026

Short version: DevToolbox does not collect, store, or transmit any personal data. All tools run entirely in your browser. Nothing you type or upload leaves your device.

What data we collect

We do not collect any personal data. We do not have user accounts, contact forms, newsletters, or any mechanism for collecting personal information.

The tools on this site process data you provide — such as text, JSON, images, or URLs — entirely within your browser. This data is never sent to any server operated by DevToolbox or any third party.

Browser storage

Some tools use your browser's local storage to save data between sessions. This data stays on your device and is never transmitted anywhere. Examples include:

  • The Markdown Editor saves your draft to local storage so you do not lose work between sessions.
  • The Color Picker saves your saved color palette to local storage.

You can clear this data at any time by clearing your browser's site data for this domain.

Hosting and infrastructure

This site is hosted on GitHub Pages, a static site hosting service provided by GitHub, Inc. When you visit this site, GitHub may collect standard web server logs including your IP address, browser type, and pages visited. This is standard practice for web hosting and is governed by GitHub's privacy policy.

DevToolbox does not have access to these logs and does not use them for any purpose.

Third party libraries

Some tools load JavaScript libraries from third party CDNs. These are loaded from:

  • jsDelivr (cdn.jsdelivr.net) — for the QR code generation library
  • Cloudflare cdnjs (cdnjs.cloudflare.com) — for the YAML parsing library
  • Google Fonts (fonts.googleapis.com) — for the Inter font used on the site

These requests may allow the CDN providers to see your IP address and browser information as part of normal CDN operation. None of these providers receive any data you enter into the tools.

Analytics

This site does not currently use any analytics service. We do not use Google Analytics, Mixpanel, or any other tracking or analytics tool. There are no tracking pixels, fingerprinting scripts, or cookies on this site.

Advertising

This site does not currently display any advertising. If advertising is added in the future this policy will be updated to reflect how ad networks handle data.

Children

This site is intended for general audiences including developers of all ages. We do not knowingly collect any information from anyone including children under the age of 13, because we do not collect any information from anyone at all.

Changes to this policy

If this policy changes, the updated version will be posted on this page with a new last updated date. Since we do not collect contact information we cannot notify users directly of changes.

Contact

If you have any questions about this privacy policy you can open an issue on the GitHub repository.
